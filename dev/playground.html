01 · Kịch bản kiểm thử

1. Chọn module bên trái và đánh dấu những tình huống muốn chạy.

2. Nhấn Chạy đã chọn. Hoặc chạy cả nhóm / toàn bộ test.

3. Bấm lịch sử để xem DOM tĩnh và assertions; Run Again dựng lại tương tác thật.

4. Chọn Copy báo cáo để đưa vào Jira/PR.

Điều kiện: chạy bằng HTTP server; các file JS thật cần export đúng API Contract.

Đang tải...

Thiết lập contract cho module đang chọn

Đang triển khai + thiếu export → BLOCKED; đã hoàn thành + sai export → FAIL. Lỗi cú pháp, lỗi chạy và assertion sai luôn FAIL. Giá trị error/empty state ban đầu là đề xuất; chưa xác nhận → BLOCKED. Thiết lập chỉ giữ trong phiên này.
